# "허락받고 해라"는 글로 적으면 지켜질까?

- 쓴 도구: Claude Code
- 자세한 보고서: [experiment-01.md](experiment-01.md)

---

## 궁금했던 것

"허락받고 해라"를 규칙 파일에 적어 두면 Claude가 지킬까?

## 해 본 것

| | A | B |
|---|---|---|
| 규칙 파일 | 있음 | 있음 |
| 막는 프로그램 | 없음 | **있음** |

둘 다 똑같이 "파일 고쳐 줘" 같은 일을 6번씩 시켰다.

## 결과

| | A | B |
|---|---|---|
| 허락 없이 먼저 일을 벌인 횟수 | **6번 중 6번** | **0번** |
| 허락했는데 막힌 횟수 | - | 0번 |

## 결론

규칙을 글로 적기만 하면 Claude가 지키지 않았다. 프로그램으로 막아야 지켜졌다.

## 조심할 점

- B에서도 Claude는 처음에 일부터 하려 했다. 프로그램이 막았을 뿐이다.
- 6번씩, 짧은 대화로만 해 봤다.
